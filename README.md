# rothgar/tap

A Homebrew tap for tools maintained by [@rothgar](https://github.com/rothgar).

## Install

```sh
brew tap rothgar/tap
```

## Formulas

| Formula | Version | Description |
|---------|---------|-------------|
| [awsls](Formula/awsls.rb) | 1.16.0 | [A list command for AWS resources](https://github.com/jckuester/awsls) |
| [eks-thw](Formula/eks-thw.rb) | 1.0.0 | [Meta package for EKS The Hard Way](https://github.com/rothgar/EKS-the-hard-way) |
| [k](Formula/k.rb) | 0.4.2 | [Experimental kubectl wrapper for advanced multi-cluster management](https://github.com/rothgar/k) |
| [kvmm](Formula/kvmm.rb) | 0.2.4 | [KVM Manager — manage multiple HTTP KVM devices from CLI or web UI](https://github.com/rothgar/kvmm) |
| [nerdctl](Formula/nerdctl.rb) | 0.15.0 | [Docker-compatible CLI for containerd](https://github.com/containerd/nerdctl) |
| [spacey](Formula/spacey.rb) | 0.1.3 | [Twitter Spaces search CLI](https://github.com/rothgar/spacey-cli) |
| [talos-fuse](Formula/talos-fuse.rb) | 0.3.0 | [Mount Talos API resources as a FUSE filesystem](https://github.com/rothgar/talos-fuse) |
| [tsv-utils](Formula/tsv-utils.rb) | 2.2.0 | [Utilities for tabular data files](https://github.com/eBay/tsv-utils) |

## Usage

Install any formula with:

```sh
brew install rothgar/tap/<formula>
```

For example:

```sh
brew install rothgar/tap/talos-fuse
```
